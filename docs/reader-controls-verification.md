# 音量键翻页与关闭动画：实机验收

## 设置入口

- Android：阅读器 → 阅读设置 → 操作 → 音量键翻页，默认关闭。
- iOS/iPadOS：不显示音量键翻页开关，不拦截音量键。
- 全平台：我的 → 设置 → 关闭动画，默认关闭（保留原有动画）。
- 两个选项保存到设备偏好，重启后保留，互不依赖。

## 验收步骤

1. 在 Android 开启音量键翻页。翻页模式下，音量减下一页、音量加上一页；滚动模式下按约一屏移动。到章节边界再次按键，存在相邻章节时切章。
2. 长按音量键只翻一次，不应连续跳章；阅读时不弹出系统音量条。
3. 打开阅读设置、目录或图片查看器，此时音量键应恢复系统音量控制。返回阅读器后应恢复翻页。退到书籍详情页、锁屏再解锁、切到其他应用再返回，也分别检查。
4. 关闭该开关后，阅读器内应正常调节音量。重启检查开关持久化。
5. 开启全局“关闭动画”，测试点击翻页、音量键翻页、左右滑动与进度条跳转：应立即切换，不显示横移过渡；滚动模式按音量键也应立即移动。长按复制和插画放大仍应可用。
6. 在首页、动态、书架、评论、设置之间切换，打开/关闭弹窗及面板，检查界面直接切换、图片无渐显。加载圈、进度条与下拉刷新保留正常加载动画，完成后消失。
7. 关闭“关闭动画”，以上页面和翻页动画应恢复；返回之前已经打开的页面也检查一次。
8. iPhone/iPad 检查阅读设置无音量键选项，全局动画开关可用。阅读模式切换和进度保存不应出现额外跳动。

## 边界

- 只控制 Yomiru 应用界面动效，不控制系统键盘、系统分享面板或图片自身包含的 GIF 动画。
- 不修改阅读任务计时、网络重试或缓存失效时间。
- 电子书设备必须把实体键映射为 Android 音量加/减键；厂商自定义键码不在本次映射范围内。
- 未改变墨水屏硬件刷新模式；残影与全刷策略由设备系统控制。
